# 8051 Experiments (CAT 2 – CAT 7)

This directory contains our bare-metal Embedded C lab experiments on the AT89S52 microcontroller (clocked at 11.0592 MHz) developed in Keil µVision. Each task folder is a standalone project complete with its project definition (`*.uvproj`), startup assembly (`STARTUP.A51`), C source files, pre-compiled firmware in `Objects/*.hex`, documentation, and a Wokwi circuit diagram.
