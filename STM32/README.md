# STM32 Experiments (CAT 8 – CAT 15)

This directory contains our STM32 experiments utilizing the STM32 HAL framework configured via STM32CubeMX. Each task folder is set up as a dual-IDE project containing the CubeMX device configuration (`*.ioc`, `.mxproject`), application source code and HAL drivers (`Core/`, `Drivers/`), Keil MDK project files (`MDK-ARM/`), and STM32CubeIDE project files (`.project`, `.cproject`), alongside an experiment README and circuit schematic.
